# navecher-web

Фронт сервиса «На вечер» — аренда вечерних нарядов из шкафов девушек, Москва.
Владелица выставляет вещь, арендатор находит её и запрашивает вечер; оплата и залог — при встрече.

Что здесь:
- сайт: каталог с фильтрами, карточка вещи, правила сделки, калькулятор для владелиц;
- `/app` — кликабельный прототип мобильного приложения;
- этот же код станет Telegram Mini App.

Стек: React, TypeScript, Vite.

Данные и раздача собранного сайта — в [navecher-api](https://github.com/IlushaSPB/navecher-api).
